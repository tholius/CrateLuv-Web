How to use CrateLuv
CrateLuv is an app which will let you set a timer and some contacts so that if you leave your pet crated while you are gone, and are unable to return in time, it will notify a list of your contacts to try to find someone to rescue your pet.
-	Create an account using your email.
-	Go to the Contacts screen and add at least one contact. If you enter a phone number, CrateLuv will attempt to get their permission for texting. Similarly, they will get an email asking for permission to send them emails about your crated pet.
-	Go back to the main screen, and select how long you will be gone. There is a box where you can add specific rescue instructions which will be sent to each contact in order.
-	The time can be set to 3 minutes to try it out.
-	Start the timer. 
-	When the timer expires, it will try to get ahold of you, then wait for a certain amount of time, the grace period, (configurable in your Profile, default 15 minutes) before notifying the first contact. 
-	If you do not respond, then it notifies the first contact, and waits for the grace period to run out (15 minutes or whatever you configured), then proceeds down the list of contacts attempting to notify each one until someone responds, in the same manner.
-	When someone responds, or if you cancel the timer, then it tells anyone who it asked to respond that you have returned and can take care of your pet.
Flow:  <initial timer runs> <App tries to notify you><grace period><first contact notified>
	<grace period><second contact notified><… etc…>
-	The contacts may be re-ordered on the contacts screen (long press). On the main screen you can turn individual contacts on and off using the checkbox.
-	FOR TESTING ONLY you can set a grace period of 2 minutes but 15 is more reasonable for actual use. And you can set a 3 minute crate rescue time (FOR TESTING). This BETA version has all features enabled.
