How to install on Android

  1. Open this page on your Android phone.
  2. Tap the download button above.
  3. When the APK finishes downloading, tap it to open.
  4. If Android blocks the install, tap Settings.
  5. Allow installs from your browser, usually Chrome.
  6. Go back and tap the APK again.
  7. Tap Install.
  8. Open CrateLuv and log in or create an account.

After installing

Please allow notifications when prompted. CrateLuv uses notifications to alert you when a crate timer expires.

If something does not work, please send a note describing what happened, what phone you are using, and the app version shown in CrateLuv.

How to Use CrateLuv

CrateLuv lets you set a timer and choose emergency contacts so that if you leave your pet crated while you are away and cannot return in time, the app will notify your contacts in order until someone responds.

Getting Started

  1. Create an account using your email. ** Note that you must navigate to the Profile screen and enter the code you were texted to enable SMS alerts. This will be updated in a future version.
  2. Go to the Contacts screen and add at least one contact.
    • If you enter a phone number, CrateLuv will attempt to get permission to send text messages. The initial text is sent from your phone, so please click Send (in your messaging app) to send the initial text to your contact.
    • Contacts will also receive an email asking permission to receive rescue notifications.
  3. Return to the main screen and choose how long you expect to be gone.
  4. Optionally enter rescue instructions such as: "Key is under the flowerpot".
  5. You can use the 3 minute timer for testing.
  6. Tap Start Timer.

What Happens When the Timer Expires

When the timer expires:

  1. The app first attempts to notify you.
  2. It then waits for the configured grace period (default 15 minutes, configurable in Profile settings).
  3. If you do not respond, the first contact is notified.
  4. If nobody responds, CrateLuv continues down the contact list one at a time, waiting the grace period between each contact.
  5. Once someone responds — or if you cancel the timer — CrateLuv sends a follow-up message indicating that your pet is no longer in danger.

Flow

<crate timer runs> → <app notifies you> → <grace period> → <first contact notified> → <grace period> → <second contact notified> → ...

Managing Contacts

  • Contacts can be reordered on the Contacts screen using long press.
  • On the main screen you can enable or disable individual contacts using checkboxes.

Beta Testing Notes

  • FOR TESTING ONLY: You may set the grace period to 2 minutes.
  • FOR TESTING ONLY: You may use the 3 minute crate timer.
  • This beta version currently has all features enabled.
